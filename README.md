# Web Application Security Assessment

## Overview
Hands-on web application security assessment performed in an authorized lab environment to develop practical VAPT skills.

The project focused on manual vulnerability validation, automated scan-result analysis, evidence collection, risk assessment, CWE/OWASP mapping, remediation recommendations, and security reporting.

> **Note:** This is a hands-on learning project performed in an authorized lab environment. It does not represent employment, commercial client work, or unauthorized testing.

## Security Findings

The assessment included hands-on validation of:

- SQL Injection (CWE-89)
- IDOR / Broken Object Level Authorization (CWE-639)
- Session Fixation (CWE-384)
- Cleartext Transmission of Credentials over HTTP (CWE-319)
- Insecure Session Cookie Configuration / Missing Secure Attribute (CWE-614)
- Parameter Tampering and application business-logic testing
- Automated vulnerability scan review and false-positive triage

## Tools Used

- Burp Suite Professional
- Kali Linux
- Nmap
- Nessus
- Wireshark
- Browser Developer Tools

## Assessment Approach

1. Application and attack-surface review
2. Manual request/response analysis
3. Authentication and session testing
4. Input and parameter manipulation
5. Manual vulnerability validation
6. Automated security scanning
7. CWE and OWASP Top 10 mapping
8. Evidence collection
9. Risk and business-impact analysis
10. Remediation and retest recommendations

## Reporting

A structured security assessment report was prepared containing:

- Executive Summary
- Scope and Methodology
- Vulnerability Findings
- CWE / OWASP Mapping
- Technical Evidence
- Risk Assessment
- Business Impact
- Remediation Recommendations
- Retest Criteria

## Key Learning

This project strengthened my practical understanding of how vulnerabilities are discovered, manually validated, documented, mapped to security standards, and communicated through a professional security assessment report.
